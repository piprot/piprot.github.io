开工前四件事 · 备好钥匙，查一遍家底

前三件各 10 分钟；第四件几分钟，给网站开一条「读者来信」通道

① GitHub 注册 + 领「钥匙」 1. 打开 github.com → Sign up：填邮箱、密码、用户名，去邮箱点验证链接；
2. 登录后右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic)；
3. Generate new token (classic) → 起个名字（如 chai）→ 勾选 repo → Generate；
4. 复制 ghp_ 开头的一串存好（只显示这一次）——这就是指令卡 ① 要交的「钥匙」。
卡住了？详细图文见 跟做手册第 1 节
② WorkBuddy 安装 + 注册 1. 打开 www.workbuddy.cn → 下载对应你电脑的版本，安装；
2. 首次打开，按提示注册并登录；
3. 新开一个对话——下面四张指令卡就粘在这里用。
③ 第一期家底体检 · ima / 公众号 / 工作流 1. ima：打开 ima.qq.com 扫码登录——知识库和素材还在；设置 → 开放 API 里的 Client ID / API Key 还在（忘了就在这页重置一份）；
2. 公众号：登录 mp.weixin.qq.com——草稿箱里第一期的素材和草稿还在；
3. 工作流：在 WorkBuddy 对话里说「跑一次第一期的工作流」——能出稿就是活的。哪一步断了别慌，带着问题来现场，讲师带你补。
第一期怎么配的忘了？见 第一期跟做手册
④ QQ 邮箱注册 + 开 IMAP · 给网站开「读者来信」通道 1. 没有QQ邮箱的：mail.qq.com 注册一个 QQ 号即得邮箱（建议专门用一个号收读者来信，别用主号）；
2. 登录 mail.qq.com 网页版 → 设置 → 账户 → 找到「POP3/IMAP/SMTP」服务 → 开启 IMAP/SMTP 服务；
3. 按提示发短信验证，生成 授权码（16 位字母，只显示一次）——它不是 QQ 密码，是指令卡 ③ 要交的「信箱钥匙」；
4. 这个邮箱会挂到你的网站页脚，读者来信它收，WorkBuddy 只读拉取——你的私人邮箱不用暴露。
卡住了？详细图文见 跟做手册「邮箱通道」节

🔁 指令卡 ④ 装的技能，跑的是这样一个圈

第一期跑的是一条线（九步全自动：库 → 稽核 → 公众号），第二期把线弯成了圈——网站上线之后，读者来信、全网热点、运行状况每天自动流回你的知识库，下一篇写什么，系统会告诉你。

出 · 写一篇，两处上线（1–5）
1批选题每周一自动递周报+开「待批阅」工单：上周体检几天全绿、本周最热五条、选题建议。你勾 1–2 条关掉——全流程唯一要你拍板的地方。人工闸门
2取素材打开 ima：批过的选题在「热点选题」目录，撑它的素材就在库里，现成。
3出稿对 WorkBuddy 说「按雷达发一篇」，它取素材、成稿、自检。
4双出口推进 GitHub 仓库自动上线：网站多一篇，公众号粘贴版同步备好。写一次，两处开花。
5回存成稿归档回 ima。库厚了一页。
回 · 每天 09:17，机器人上岗（6–9）
6晨检七项只读体检：页面、数据、AI 服务挨个看，只看不碰。偶发打不开隔 60 秒复测，两轮都挂才算真故障——真故障自动开工单发你邮箱。
7收信页脚反馈邮箱的读者来信自动归档进 ima「网站邮箱信息」，同一封绝不收两遍。
8扫热点微博/知乎/抖音/头条四榜只留与你站内兴趣相关的，按热度进「热点选题」。写过的题不再推。
9记账体检结果、命中热点每天各记一行；周一这些数字汇成周报，回到第 1 步。
🧠 圈转一圈，库厚一寸：第一期是你推着产线走，第二期是网站自己转，你只管批。选题永远是现成的，故障永远有人盯着——你只做两件事：周一五分钟批阅，和写。
🛡️ 全程只读体检七项检查全部 GET 只看不碰，绝不写线上任何内容。
📮 来信原文逐字保留归档不删信不改信，读者信号原样进库。
