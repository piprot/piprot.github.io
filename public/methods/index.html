方法库

把用得上的框架，摆到台面上

十条方法卡，按「营销业绩 / 管理数字化 / 咨询决策」分了组。每条只写要点和适用处，方便你对照、也方便你质疑。

A · 营销业绩提升

把成交拆成可练的动作

这一组来自公开销售课程笔记的脱敏提炼与业务研究笔记，去掉了行业专属话术与客户信息，只留通用框架。

A01 / 流程

需求导向销售五环与成交四要素

五环：电话约访 → 接触面谈 → 方案呈现 → 异议处理 → 促成。四要素：信任是前提、需求是基础、帮助与价值是关键、急迫性是临门一脚。核心竞争力是专业度与服务，不是产品或价格。

A02 / 异议

异议处理五步法

倾听 → 认同 → 澄清 → 转换 → 促单。异议不等于拒绝，而是兴趣信号；四个常见根源是信任、需求未挖掘、方案不匹配、不急迫。每处理完一个异议，要顺势回到促成。

A03 / 节奏

促成的 40 / 30 / 20 / 10

一种值得对照的时间分配：约 40% 建立信任、30% 观念培养与需求激发、20% 产品说明，促成本身只占 10%。促成不是临门强推，而是前面都做实之后自然发生的结果。

A04 / 表达

FABE 价值翻译

把「产品有什么功能」翻译成「对方能得到什么、能自己算出来的结果」。价值展示的关键不是罗列参数，而是让对方看见差距与收益。

A05 / 诊断

QuickStar 四步法

调频道（身份切换）→ 找问题（三层风险穿透）→ 抛法条（专业击穿认知盲区）→ 给方案。要点在前 80% 的时间用于诊断，方案本身只占后段一小截。

A06 / 复盘

五步复盘法

达成风险共识 → 回归持仓分析 → 强调再平衡 → 回顾账户目标 → 讨论配什么。可迁移的部分是顺序：先对齐风险认知，再谈具体配置，不反过来。

B · 管理数字化

先理流程，再谈工具

这一组是公开资料的要点提炼；本站只做索引与提炼，不转载原文。

B01 / 流程

流程化思维

以系统性、结构化的方式分析和优化业务活动：把复杂任务拆成有序步骤，明确节点关系与规则，让结果可预测、可交接、可复制。

B02 / 沉淀

知识库两层结构

主目录下只放「资料」与「总结」两层：前者存原始解析内容，后者存整理后的结构化结论。每日做主题分类、去重合并，出一份清单，人工确认后才入库。

B03 / 复用

对话—沉淀—复用闭环

每次与 AI 对话后自动提取有效信息、生成结构化单页文档回存知识库；新任务先检索历史案例与方法再出方案。价值在知识复利，不在单次提速。

C · 咨询与决策

把纠结变成能算的题

C01 / 取舍

ROI 科学决策三角形

宽度：把关键收益项与关键成本项列清楚；深度：给优先级、做部分定量与定量公式；高度：放回长期视角。三个维度分开看，才不会在单点上反复摇摆。

C02 / 盘点

资源盘点九维

时间、财产、认知、工作、心理、关系、身体、生活、精神。动手之前先回答「我有什么」，再谈「我要做什么」——顺序反了，计划就容易悬空。

C03 / 专题

升维领导力

管理困境先看层级：事件、流程，还是系统。单开的专题里写清两类问题、十项能力、九章情境与五步训练闭环，可直接对照使用。
